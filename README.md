# วิเคราะห์สัดส่วนใบหน้า

เว็บหน้าเดียว (`index.html` ไฟล์เดียว ไม่มี build): เปิดกล้อง → กด "ถ่ายภาพ" → ได้ผลวิเคราะห์ทันที ประมวลผลในเบราว์เซอร์ รูปไม่ถูกส่งออก

ผลที่ได้: สามส่วนแนวตั้ง, ห้าส่วนแนวนอน, ดัชนีใบหน้า, ความสมมาตรซ้าย–ขวา พร้อมเส้นไกด์ทับบนรูป

## รันในเครื่อง

กล้องต้องใช้ https หรือ localhost:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## Deploy ด้วย GitHub Pages

Push `index.html` → Settings → Pages → Branch: `main` / `(root)` → ได้ลิงก์ `https://<user>.github.io/<repo>/`

## เทคโนโลยี

[MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) (`@mediapipe/tasks-vision@0.10.14`, Apache-2.0) ไลบรารีโหลดจาก jsDelivr และโมเดลจาก Google Storage ต้องมีอินเทอร์เน็ตตอนเปิดหน้า

## ข้อจำกัด

- ต้องหน้าตรง แสงสม่ำเสมอ ไม่ใส่แว่น ผมไม่บังหน้า ปากปิด ไม่เงย/ก้ม
- โมเดลไม่เห็นไรผมจริง ใช้ขอบบนโครงหน้าแทน ส่วนบนของสามส่วนจึงอาจสั้นกว่าจริง
- ห้าส่วนใช้ขอบแก้มแทนหู ส่วนนอกจึงมักต่ำกว่า 20%
- เป็นค่าประมาณจากจุดบนภาพ ไม่ใช่คะแนนความสวยหรือการวินิจฉัยทางการแพทย์
- ทดสอบสูตรด้วยข้อมูลสังเคราะห์แล้ว แต่ยังไม่ได้ทดสอบกับกล้องจริงในเบราว์เซอร์
